# Prompt para una iteración de cambio

Quiero cambiar la funcionalidad con esta petición:

> [ESCRIBE AQUÍ EL CAMBIO]

Sigue este orden y muestra cada modificación:

1. Identifica qué requisitos y criterios de aceptación cambian.
2. Propón la actualización de `docs/specs/01-focuslist-spec.md`.
3. Actualiza `docs/specs/02-focuslist-plan.md` y `docs/specs/03-focuslist-tasks.md`.
4. Implementa el cambio en código.
5. Agrega o ajusta pruebas de aceptación y regresión.
6. Ejecuta la suite completa.
7. Revisa la convergencia: requisitos cubiertos, tareas pendientes, riesgos y supuestos.

No declares éxito solo porque el código compila. Cita el comando ejecutado y su resultado. Si la petición está fuera de alcance, dilo antes de implementar.
