# Checklist de calidad de requisitos y convergencia

## Requisitos

- [x] Cada historia tiene una persona usuaria y un objetivo.
- [x] Los títulos vacíos y demasiado largos están definidos.
- [x] El estado y los filtros tienen vocabulario cerrado.
- [x] La repetición de `done` tiene un comportamiento definido.
- [x] El ID inexistente tiene un comportamiento definido.
- [x] El formato de persistencia está documentado.
- [x] El alcance excluye red, concurrencia y autenticación.

## Implementación

- [x] Existe un test por regla importante.
- [x] La CLI se puede ejecutar desde un checkout limpio.
- [x] El README muestra comandos de ejemplo.
- [x] La suite pasa sin dependencias de red.
- [x] El código no agrega funciones fuera de alcance.

## Convergencia

- [x] Spec, plan y tareas describen la misma v1.
- [x] La implementación cumple el comportamiento observable.
- [x] Los tests pasan.
- [x] Las limitaciones están registradas.
