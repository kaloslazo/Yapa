# Chatbot de preguntas frecuentes

Asistente local de búsqueda y respuestas preparadas, sin LLM, claves ni servicios nuevos en AWS. Reutiliza las diez preguntas de Cómo funciona y Explorar. Ofrece temas, búsqueda sin tildes con sinónimos, respuestas elegidas por el usuario y un estado sin coincidencias. No consulta pagos personales, no promete acciones y no envía conversaciones a un servidor. El historial vive solo en memoria y se puede reiniciar. El panel admite teclado, Escape y pantallas pequeñas.

Aceptación: buscar «pagué» encuentra pagos; «no llegó mi compra» ofrece ayuda de entregas; una consulta desconocida no inventa una respuesta; cerrar restaura el foco. Pruebas y ejecución en README de esta rama.
