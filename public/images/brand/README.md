# Identidad visual de Yapa

`yapa-mark.png` es un símbolo generado con IA para la identidad de Yapa: una
bolsa de compras abstracta con una sonrisa y hojas, en terracota y tinta.

- Uso: marca principal del header.
- Formato: PNG RGBA transparente, 512 × 512 px.
- Prompt: símbolo minimalista de una bolsa de compras y una sonrisa, flat,
  vector-like, sin texto, sin degradados y sin fondo.

`yapa-farmer-banner.png` es una ilustración editorial generada con IA de una
agricultora con una canasta de productos para el hero. Se conserva como PNG
RGBA transparente para integrarse con el fondo crema de la interfaz.
